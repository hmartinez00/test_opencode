# Plan de Implementacion: Directorio Maestro por Defecto, Prompt Interactivo y Entregable Autocontenido (005-directorio-maestro-rutas-y-zip)\n\n**Fecha**: 2026-08-24\n\nEste plan detalla la estrategia de implementacion para la Iteracion 005, que refactoriza la gestion de rutas de salida, la interaccion con el usuario y la ubicacion de `outputs.zip`.\n\n---\n\n## 1. Vision General de la Implementacion\n\nLa implementacion se centrara en introducir una funcion centralizada (`resolve_output_base_dir()`) en `pra_helper.py` para gestionar la logica del directorio maestro (default, override por `PRA_OUTPUT_DIR`, validacion de existencia, prompt interactivo y manejo de no-TTY). `pra_orchestrator.py` hara uso de esta misma logica. Ademas, se modificara `cmd_zip` para guardar `outputs.zip` dentro de la carpeta del proyecto y excluirlo de su propio contenido. La suite de pruebas se adaptara para cubrir estos nuevos comportamientos, incluyendo el mocking de `stdin` y `isatty`.\n\n---\n\n## 2.
